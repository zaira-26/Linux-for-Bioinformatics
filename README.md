# Linux for Bioinformatics

This repository contains my Linux command-line and Bash scripting practice developed while preparing for bioinformatics and computational biology research.

The aim of this repository is to build a strong foundation in Linux, automate repetitive tasks using Bash, and gain experience working with biological sequence files commonly used in bioinformatics.

## Scripts Included

| Script | Description |
|---------|-------------|
| **01_hello.sh** | Introduction to Bash scripting using `echo`. |
| **02_first_script.sh** | Demonstrates variables and basic script execution. |
| **03_gene_search.sh** | Searches for user-specified genes within a FASTA file using `grep`. |
| **04_compare.sh** | Demonstrates command-line arguments (`$1`, `$2`, etc.). |
| **05_loop.sh** | Uses a `for` loop to process multiple FASTA files. |
| **06_while_loop.sh** | Demonstrates interactive `while` loops with user input. |
| **07_functions.sh** | Organizes code using reusable Bash functions. |
| **08_array.sh** | Demonstrates Bash arrays and iteration through array elements. |
| **09_check_file.sh** | Checks file and directory existence using Bash test operators. |
| **10_file_test.sh** | Demonstrates additional file validation techniques in Bash. |
